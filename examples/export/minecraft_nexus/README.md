# Nexus Menu - Minecraft GUI

Generated by [Fimgui](https://github.com/dis3j/FImgui) for **Minecraft 1.21.1, Fabric (Yarn mappings)**.

## Add to your mod

Copy `src/` into your mod project (it merges with your `src/main`). The mod id is `examplemod` and the package `com.example.examplemod.client.gui`.
The screen is client-only code: keep it in your client source set or behind a client check.

Open the menu, for example from a key binding:

```java
MinecraftClient.getInstance().setScreen(new NexusScreen());
```

Read or change the state from your code:

```java
NexusScreen s = new NexusScreen();
boolean aim_autofire = s.menu.aim_autofire;
boolean aim_enabled = s.menu.aim_enabled;
boolean aim_visible = s.menu.aim_visible;
boolean auto_strafe = s.menu.auto_strafe;
boolean bhop = s.menu.bhop;
int bone = s.menu.bone;
boolean box_esp = s.menu.box_esp;
String cfg_name = s.menu.cfg_name;
float esp_dist = s.menu.esp_dist;
float fov = s.menu.fov;
boolean health_bar = s.menu.health_bar;
boolean name_tags = s.menu.name_tags;
boolean skeleton = s.menu.skeleton;
float smooth = s.menu.smooth;
boolean streamproof = s.menu.streamproof;
int tab = s.menu.tab;
boolean watermark = s.menu.watermark;
```

## Files

- `NexusMenu.java` - the design: state fields, layout, interaction, animations (loader independent)
- `NexusScreen.java` - the Screen and its drawing adapter for Fabric
- `fimgui/` - Fimgui Java runtime (animations, input, widgets)
- `assets/examplemod/textures/gui/nexus/` - baked layers (fills, gradients, strokes, shadows, images, icons) at 2x
- `assets/examplemod/font/` - TTF font providers for the design fonts

## How it maps

- Shapes with effects are baked into textures, plain rectangles use `fill`, texts use the Minecraft text renderer with your TTF fonts.
- Buttons, tabs, checkboxes, sliders, dropdowns and text fields work like in the Fimgui preview; hover and active colors fade in.
- Entrance, loop, hover / press animations and keyframe timelines run through `FimAnim`, the same math as the editor.
- The menu is fitted into the window (never scaled above 1 design px per GUI px).

## Limitations

- Background blur and glass are baked without the world behind them. GIFs and videos show their first frame.
- Only TrueType (.ttf) fonts can be shipped; others fall back to the vanilla font.
