# Patch notes

Каждый релиз обязан иметь раздел `## x.y.z` в этом файле. Workflow `.github/workflows/release.yml` не опубликует релиз без патчноута или если сборка не прошла. Текст раздела становится описанием релиза на GitHub и показывается в Fimgui в окнах «Что нового» и «Доступно обновление».

## 1.3.0 — 2026-11-22

### Новое
- **Поворот слоёв**: поле Rotation в Design, вращение мышью за углом выделения (Shift — шаг 15°), ручки и ресайз по осям повёрнутого слоя. Поворот экспортируется в C++, Java (Minecraft), CSS и SVG; на таймлайне появилась дорожка **Rotation**.
- **Перо (P)** и редактирование векторов: угловые и гладкие точки, замыкание пути, редактор точек и ручек по двойному клику. Пути экспортируются в C++ (`fim::DrawPath`), SVG и Minecraft.
- **Градиенты Radial, Angular и Diamond** и градиенты с любым числом стопов.
- **Колорпикер как в Figma**: Custom / Libraries с сохранёнными цветами, выбор типа градиента, «перевернуть» и «повернуть на 90°», маркеры стопов и список Stops; у изображений — Fill / Fit / Tile, превью с загрузкой и коррекция Exposure / Contrast / Saturation / Temperature / Tint / Highlights / Shadows; проверка контраста с отметками AA / AAA и линией AA на квадрате цвета.
- Новые режимы наложения: Darken, Lighten, Exclusion, Plus darker.
- **Свои пресеты анимаций** во вкладке Motion (My presets): сохранить анимацию слоя вместе с ключевыми кадрами, применить, переименовать, обновить, удалить, импорт и экспорт в файл.
- Таймлайн: ключи выделяются рамкой с зажатой ЛКМ (Shift / Ctrl добавляют к выделению).

### Улучшено
- Тени размываются по Гауссу (как в Figma и CSS), внутренняя тень повторяет скругления.
- Слои, скрытые через Show when, не занимают места в auto layout — в редакторе и в экспорте (раскладка таких фреймов считается в рантайме: `fim::AutoLayout`, `FimUi.autoLayout`).
- Видео до 1920 px декодируются без уменьшения.

## 1.2.0 — 2026-11-22

### Новое
- Шрифты растеризуются через **FreeType** (2.13.3) с мягким хинтингом: текст в интерфейсе и на холсте чётче, мелкие подписи читаются лучше, межбуквенные расстояния как в дизайне.
- Таймлапс: флаги `--ops-stream` и `--record` показывают, как дизайн собирается из потока операций, и записывают кадры; `examples/scripts/make_timelapse.py` собирает из них GIF.
- Новые примеры с анимациями: экран входа (`login_demo`) и мини-плеер с эквалайзером на ключевых кадрах (`player_demo`).

## 1.1.0 — 2026-11-22

### Новое
- **Экспорт в Minecraft (Java Edition 1.21.1)** для Fabric и NeoForge: класс Screen, класс меню с состоянием, Java-runtime Fimgui (анимации, кнопки, вкладки, чекбоксы, слайдеры, выпадающие списки, поля ввода), запечённые текстуры слоёв и шрифты дизайна как TTF-провайдеры. Export → Minecraft Java.
- **Таймлайн с ключевыми кадрами**, как в Adobe: панель под холстом (Alt+T), линейка времени, плейхед, play / loop, дорожки Position X / Y, Scale, Opacity, ключи-ромбы с перетаскиванием и easing по правому клику, траектория движения на холсте с точками, которые можно двигать. Анимация «Keyframes» работает в редакторе, в C++ и в Java-экспорте, проигрывается при появлении, в цикле, по наведению, нажатию или активному состоянию.
- **Колорпикер как в Figma**: вкладки Solid, Gradient (стопы, угол), Pattern, Image, Video, Shader (Aurora, Mesh, Waves, Radial glow, Plasma), режим наложения заливки (Normal, Plus lighter, Multiply, Screen) и проверка контраста WCAG (AA / AAA). Квадрат насыщенности, полосы оттенка и прозрачности, пипетка с экрана, форматы Hex / RGB / HSL / HSB, цвета со страницы.
- Медиа-заливка (паттерн, картинка, видео, шейдер) показывается отдельной строкой в Fill.
- Логотип рисуется единой фигурой и не «рассыпается» в полупрозрачном виде.

### Лицензия
- Fimgui License 2.0: Fimgui бесплатен для любых проектов, включая коммерческие; свои дизайны и экспорт (код, runtime, текстуры) можно продавать. Продавать сам Fimgui нельзя.

## 1.0.0 — 2026-11-22

### Новое
- Свой заголовок окна вместо системного: логотип, крупные отдельные меню File / Edit / View / Help, название проекта, кнопки окна. Окно перетаскивается за пустое место, двойной клик разворачивает.
- Проверка обновлений при запуске: если на GitHub вышла новая версия, Fimgui покажет её патчноут и откроет страницу релиза для скачивания. Есть Help → Check for updates и «Пропустить эту версию».
- Окно «Что нового» после обновления; Help → What's new.
- Новый логотип: «Fi», где «i» — кисть.
- Панель Design переделана: подписи над полями, разделы Position / Layout / Appearance, строки Fill и Stroke с переключателем видимости, эффекты списком.
- Кнопки, поля и меню стали крупнее.
- Проекты: рабочая папка `C:\FImgui`, у каждого проекта свои fonts, images, icons, videos, export; экран Projects с превью.
- Пиксельная сетка от 400%, привязка к пикселям, Pixel preview.
- Combo и Multi-combo.
- MCP-сервер и stdio-мост для Claude Desktop / Claude Code.
- Эффекты Background blur, Glass, Texture overlay (PNG / GIF / видео), анимации и вкладка Motion.
- Встроенный чат с Claude, экспорт в готовый C++-проект для Dear ImGui.

### Исправлено
- Офскрин-рендер дизайнов с эффектами (Copy as PNG, экспорт PNG, снимок для AI) больше не падает.
- Видео с выровненными строками кадра (например 4500×3000) показывается без перекоса.
- Экспортированный `fimgui_fx_dx11.cpp` собирается без `NOMINMAX`.
